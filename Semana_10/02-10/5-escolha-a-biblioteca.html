Qual biblioteca escolher?

Atividade de teoria (10 min, em duplas). Nada será instalado nem programado: o objetivo é justificar uma escolha usando os critérios vistos na aula (prazo, equipe, design, performance, acessibilidade e manutenção). Opções: Bootstrap, Tailwind CSS, Material UI ou CSS puro.

Cenário Sua escolha Justifique em uma frase (critério decisivo)
1. Landing page de uma padaria, para entregar em 1 dia, feita por uma pessoa só.
2. Painel interno de uma empresa, com tabelas e formulários, sem layout definido pelo design.
3. Site de uma marca de moda, com visual exclusivo e animações próprias.
4. Aplicação React corporativa com dezenas de telas e vários formulários.
5. A página de contato da Bikcraft que construímos nesta semana.

Perguntas para a roda de conversa

  1. Qual a diferença entre uma biblioteca de componentes prontos e uma abordagem utility-first?
  2. Cite um ganho e um custo de usar uma biblioteca em vez de escrever o CSS.
  3. Por que dominar Flexbox e media queries ajuda a usar qualquer biblioteca?
