ÍndiceDoc 01 de 23

Guia de HTML & CSS profissional

23 documentos, da raiz ao avançado, para responder quatro perguntas: o que cada classe faz, como funcionam herança e cascata, quem vence quando duas regras brigam e como se organiza um HTML de nível profissional.

Como estudar

  1. Leia na ordem. Cada documento usa o que o anterior ensinou.
  2. Abra o DevTools (F12) em cada exemplo. Ver o CSS sendo aplicado vale mais que ler sobre ele.
  3. Faça os exercícios do documento 16 antes de passar para a trilha D.
  4. Volte ao mapa (documentos 17 a 19) sempre que não souber que tag usar.
