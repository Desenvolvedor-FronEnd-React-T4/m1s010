Página completa anotada (Bikcraft)

Juntando tudo: uma página inteira comentada linha a linha, com a justificativa de cada escolha. É a estrutura da página de contato que a turma construiu em 02-10/4-pagina-contato-final-gabarito.html. Este é o padrão correto: header, main com as seções dentro, footer. Os arquivos da atividade 4 seguem exatamente esse esqueleto.

1. HTML anotado

<!DOCTYPE html>                              <!-- avisa: HTML5 moderno -->
<html lang="pt-BR">                         <!-- idioma: leitor de tela e tradutor -->
<head>
  <meta charset="UTF-8">                     <!-- acentos corretos -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
                                              <!-- sem isto o celular finge ser desktop -->
  <title>Contato — Bikcraft</title>           <!-- aba do navegador e Google -->
  <link rel="stylesheet" href="estilo.css">
</head>
<body>

  <!-- CAMADA 2: moldura -->
  <header class="cabecalho">                  <!-- topo do SITE -->
    <a class="logo" href="index.html">bikcraft</a>
    <nav class="menu" aria-label="Principal">
      <a href="index.html">Home</a>
      <a href="bikes.html">Bikes</a>
      <a href="contato.html" aria-current="page">Contato</a>
    </nav>
  </header>

  <main>                                      <!-- conteúdo ÚNICO desta página -->

    <!-- CAMADA 3: seção hero -->
    <section class="hero">                    <!-- faixa de destaque -->
      <p class="hero-chamada">Respostas em até 24h</p>
      <h1 class="hero-titulo">Nosso contato</h1>   <!-- UM h1 por página -->
    </section>

    <!-- seção de duas colunas -->
    <section class="secao-contato">
      <div class="coluna-dados"> ... </div>    <!-- div: só organiza layout -->
      <form class="coluna-formulario">          <!-- form: tag certa, não div -->
        <div class="campo">
          <label for="nome">Nome</label>
          <input id="nome" type="text" required>  <!-- label ligado por for/id -->
        </div>
        <button class="botao" type="submit">Enviar</button>
      </form>
    </section>

    <!-- lista de cards: article dentro de section -->
    <section class="lojas">
      <article class="card-loja"> ... </article>
      <article class="card-loja"> ... </article>
    </section>
  </main>

  <footer class="rodape"> ... </footer>       <!-- base do SITE -->

  <a class="topo" href="#" aria-label="Voltar ao topo">↑</a>
  <script src="script.js"></script>           <!-- último: não trava a página -->
</body>
</html>

2. CSS anotado (na ordem do documento 20)

/* RESET + TOKENS */
* { box-sizing: border-box; }
:root { --azul: #1b4f72; --gap: 16px; }

/* BASE: herança trabalhando — fonte e cor declaradas UMA vez */
body { margin: 0; font-family: Arial, sans-serif; line-height: 1.6; color: #263238; }
a { color: inherit; }
input, button { font: inherit; }

/* ESTRUTURA / LAYOUT */
.secao-contato { display: flex; flex-direction: column; gap: var(--gap); padding: 40px 16px; }
@media (min-width: 768px) {
  .secao-contato { flex-direction: row; }       /* mobile-first: duas colunas só no tablet */
  .coluna-dados, .coluna-formulario { flex: 1; }
}

/* COMPONENTES (classe simples, peso 0-0-1-0) */
.cabecalho { display: flex; justify-content: space-between; align-items: center; padding: 12px 16px; }
.campo { display: flex; flex-direction: column; margin-bottom: var(--gap); }
.botao { padding: 10px 20px; background: var(--azul); color: #fff; border: 0; border-radius: 6px; }
.card-loja { border: 1px solid #cfd8dc; border-radius: 8px; padding: 16px; }

/* ESTADOS */
.botao:hover { background: #123049; }
.menu a[aria-current="page"] { font-weight: bold; }

3. Mapa das decisões

EscolhaRegra aplicadaDoc
header, main, footer como molduraCamada 2 do mapa17
section para hero, contato, lojasCada faixa tem um tema18
article para cada lojaPeça independente18
div.campoAgrupa só para o CSS18
form, label, buttonExiste tag com significado19
Fonte só no bodyHerança10
a { color: inherit }Link não herda a cor sozinho11
Tudo com classe, sem id no CSSBaixa especificidade14, 15
Media query depois da regra baseMesmo peso, vence a última12, 20

Confira você mesmo: abra 02-10/4-pagina-contato-final-gabarito.html ao lado deste documento e localize, na página da turma, cada camada do mapa: header, main, as três section, os article, o footer. Todas estão lá, na mesma ordem.
