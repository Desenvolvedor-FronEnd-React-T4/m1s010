Exercícios: herança, cascata e especificidade

Faça sem abrir o navegador, no papel ou em dupla. Depois confira clicando em "Ver gabarito" e confirme no DevTools.

Parte 1 — Herança

Exercício 1

body { color: navy; border: 2px solid black; }

<body><p>Texto</p></body>

O p terá cor azul-marinho? E borda?

Ver gabarito

Cor: sim (color herda). Borda: não (border não herda). A borda aparece só no body.

Exercício 2

body { color: navy; }
<body><a href="#">Link</a></body>

De que cor é o link? Como faria para ele acompanhar o texto?

Ver gabarito

O link fica na cor padrão do navegador (azul), pois o navegador define uma cor própria para a. Solução: a { color: inherit; }.

Parte 2 — Cascata (ordem)

Exercício 3

.titulo { color: red; }
.titulo { color: green; }
<h1 class="titulo">Oi</h1>
Ver gabarito

Verde. Empate de especificidade; vence a última.

Exercício 4

p { color: blue; font-size: 20px; }
p { color: red; }
<p>Oi</p>

Cor e tamanho?

Ver gabarito

Cor vermelha (a última vence), tamanho 20px (ninguém discordou; a regra anterior continua valendo).

Parte 3 — Especificidade

Exercício 5: calcule o placar

SeletorPlacar (A-B-C-D)
h2
.card h2
#lojas .card h2
a:hover
ul li.ativo a
Ver gabarito

h2 = 0-0-0-1 · .card h2 = 0-0-1-1 · #lojas .card h2 = 0-1-1-1 · a:hover = 0-0-1-1 · ul li.ativo a = 0-0-1-3.

Exercício 6: quem vence?

.menu a    { color: white; }
.destaque  { color: gold; }
<nav class="menu"><a class="destaque" href="#">Loja</a></nav>
Ver gabarito

Branco. .menu a = 0-0-1-1 contra .destaque = 0-0-1-0. Correção: .menu .destaque (0-0-2-0).

Exercício 7: id contra classes

#topo { color: red; }
.a.b.c.d.e.f { color: blue; }
<p id="topo" class="a b c d e f">Oi</p>
Ver gabarito

Vermelho. 0-1-0-0 vence 0-0-6-0: a coluna B pesa mais que qualquer número na coluna C.

Exercício 8: o atalho do inline

.botao { background: blue !important; }
<button class="botao" style="background: red">Clique</button>
Ver gabarito

Azul. O !important do autor vence até o estilo inline comum.

Parte 4 — Desafio de equipe

O CSS abaixo tem 3 problemas de predominância. Encontre e corrija sem usar !important.

#cabecalho .menu ul li a { color: white; }
.botao { background: gray; }
.botao--primario { background: blue; }   /* vem antes de .botao no arquivo real */
body main section div.container p { font-size: 14px; }
.texto-grande { font-size: 24px; }
Ver gabarito
  1. Seletor longo com id (0-1-1-3): troque por .menu-link { color: white; }.
  2. Ordem: .botao--primario deve ser escrito depois de .botao.
  3. Seletor longo (0-0-1-5) impede .texto-grande de vencer: troque por .paragrafo { font-size: 14px; } e coloque .texto-grande depois.
