Árvore de decisão: div, main, section ou article?

Responda às perguntas de cima para baixo. A primeira resposta "sim" é a tag certa. A div é o último recurso: use quando nenhuma tag tem significado.

Pares que confundem

section ou div?

section: o grupo tem um tema e um título. Se você consegue nomear no sumário da página, é section.

div: só existe para o CSS (largura, grade, fundo).

Teste: "Se eu tirar o CSS, essa caixa ainda faz sentido como parte do documento?" Sim → section. Não → div.

section ou article?

article: peça independente e reaproveitável (card de produto, post, comentário).

section: pedaço de algo maior.

Teste: "Posso copiar para outro site e continua fazendo sentido?" Sim → article.

header ou section.hero?

header do site: topo com logo e menu. O hero é a primeira section do main.

Um header também pode abrir um article (título + data do post).

aside ou div.lateral?

aside: o conteúdo é complementar (links relacionados, anúncios, biografia).

div: uma coluna de layout que faz parte do texto principal.

Erros frequentes

ErroCorreção
Toda a página dentro de div ("divite")Troque pela tag semântica correspondente
Dois main na mesma páginaSó um. Os outros viram section
section sem título dentroDê um h2 ou use div
div clicável com onclickUse button (teclado e leitor de tela funcionam de graça)
section só para aplicar fundoIsso é papel de div ou classe
main dentro de sectionmain envolve as seções, nunca o contrário

As semânticas não mudam o visual. section, article e div são todos caixas em bloco. A diferença é significado: para busca, leitor de tela e outros desenvolvedores. O visual você faz com classe.
