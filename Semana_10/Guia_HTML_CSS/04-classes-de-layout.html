Classes de layout

Classes de layout dizem como os filhos de um elemento se organizam: em linha, em coluna, em grade. A regra mental: a classe vai no pai, e quem se organiza são os filhos.

Flexbox: organizar em uma direção

.flex { display: flex; }
.flex-coluna { flex-direction: column; }
.centralizado { justify-content: center; align-items: center; }
.espaco-entre { justify-content: space-between; }
.quebra { flex-wrap: wrap; }
.gap { gap: 16px; }

Quando usar: menu, barra de botões, cabeçalho, centralizar algo, linha de cards que podem quebrar.

Grid: organizar em linhas e colunas ao mesmo tempo

.grid { display: grid; gap: 16px; }
.grid-3 { grid-template-columns: repeat(3, 1fr); }
.grid-auto { grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); }

Quando usar: galeria, catálogo de produtos, layout de página inteira, qualquer coisa em "grade".

Regra prática: uma dimensão (linha ou coluna) → flex. Duas dimensões (linhas e colunas) → grid.

row e col (Bootstrap) e colunas do projeto

Em frameworks, o layout vira vocabulário pronto:

<div class="container">
  <div class="row">
    <div class="col-md-6">Dados</div>
    <div class="col-md-6">Formulário</div>
  </div>
</div>
  • row: a linha (por baixo é display: flex; flex-wrap: wrap).
  • col-md-6: "a partir da tela média, ocupe 6 de 12 partes (metade)".

Em CSS puro você cria o mesmo com nome por função, como a coluna-dados e a coluna-formulario da página de contato da Bikcraft.

Tabela das classes de layout

ClasseO que fazVai em
flex / d-flexLiga o flexboxo pai
grid / d-gridLiga o grido pai
rowLinha de colunaso pai
col, col-6Coluna e sua largurao filho
gapEspaço entre os filhoso pai
justify-*, items-*Alinha no eixo principal / cruzadoo pai
stackPilha vertical com espaço regularo pai

Erro clássico: colocar display: flex no filho e esperar que os irmãos se alinhem. O flex só organiza os filhos diretos de quem o recebe.
