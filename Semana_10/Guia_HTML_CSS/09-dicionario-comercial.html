Dicionário comercial: Bootstrap, Tailwind e CSS puro

No mercado você vai encontrar três "sotaques" de classes. Este documento é a tabela de tradução: o mesmo resultado escrito nos três estilos.

Três filosofias

Bootstrap

Componentes prontos. btn btn-primary entrega o botão inteiro. Rápido, padronizado, visual conhecido.

Tailwind

Utility-first. Cada classe é uma propriedade. Controle fino, HTML cheio de classes.

CSS puro

Você nomeia tudo. botao botao--primario. Máximo controle, mais trabalho. É o que usamos na Bikcraft.

Todos seguem mobile-first: md:w-1/2 significa "de 768px para cima".

Por que aprender CSS puro primeiro? Porque o row do Bootstrap é flex + flex-wrap, o col-md-6 é flex: 0 0 50% dentro de uma media query, e o p-4 do Tailwind é padding: 1rem. Quem entende a base lê qualquer framework.
