Os elementos de página, um por um

Ficha técnica de cada elemento estrutural: o que é, quantos pode haver, onde fica, classe típica e erro comum.

header

Cabeçalho do site: logo, menu, às vezes busca. Não é o <head> (esse é invisível e fica fora do body).

<header class="cabecalho">
  <a class="logo" href="/">bikcraft</a>
  <nav class="menu">...</nav>
</header>

CSS típico: display: flex; justify-content: space-between; align-items: center;

nav

Somente para grupos principais de links (menu, paginação, índice). Nem todo link solto precisa estar num nav. Estrutura profissional: lista dentro:

<nav class="menu" aria-label="Principal">
  <ul><li><a href="/bikes">Bikes</a></li> ...</ul>
</nav>

main

O coração da página: o conteúdo que só existe aqui. Não inclui cabeçalho, menu e rodapé repetidos em todas as páginas. Leitores de tela têm atalho que pula direto para ele.

section

Faixa temática com título. Padrão da indústria: section (faixa) + div.container (conteúdo).

<section class="lojas" aria-labelledby="titulo-lojas">
  <div class="container">
    <h2 id="titulo-lojas">Nossas lojas</h2>
    ...
  </div>
</section>

article

Item autônomo. Num catálogo, cada produto é um article; a lista deles vive numa section.

aside

Conteúdo relacionado, mas dispensável: barra lateral, caixa "leia também", propaganda, biografia do autor.

footer

Fecha o site (ou um bloco). Típico: endereço, redes, copyright, links legais.

div: o coringa

Caixa sem significado. Perfeita para três usos:

  1. Container: limitar largura.
  2. Layout: grid ou flex que agrupa filhos.
  3. Agrupamento visual: linha de formulário, par rótulo+campo.

Link ou botão? Se muda de página → a. Se executa uma ação na página (enviar, abrir menu) → button. O visual pode ser idêntico: a classe cuida disso.
