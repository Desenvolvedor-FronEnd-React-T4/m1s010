Ferramentas de Apoio — Semana 10

Extensões do VS Code e vídeo-aulas recomendadas para Responsividade, Flexbox, Especificidade e Bibliotecas

Desenvolvimento Front-End [React] T4 | Módulo 1 | Semana 10  |  Este material reúne extensões do VS Code que facilitam o trabalho da semana e vídeo-aulas curtas e objetivas (a maioria com 10 minutos ou menos) para reforçar cada tema fora do horário de aula. Nenhum vídeo substitui a aula — use-os para revisar antes ou depois do encontro.

1. Extensões do VS Code

Instale pela aba de Extensões do VS Code (Ctrl+Shift+X), buscando pelo nome ou colando o identificador na busca.

ExtensãoIdentificadorO que fazPor que ajuda nesta semana
Live Server ritwickdey.LiveServer Abre a página num servidor local, com recarregamento automático a cada salvamento Essencial para testar a responsividade — necessário para os links entre páginas do Bikcraft funcionarem de verdade
HTML CSS Support ecmel.vscode-html-css Autocomplete de classes/ids do seu CSS direto no HTML Agiliza escrever as classes de Flexbox e das seções responsivas sem erro de digitação
IntelliSense for CSS class names in HTML Zignd.html-css-class-completion Sugestão de classes já definidas no projeto (inclusive as do Bootstrap, se estiver linkado) Ajuda a lembrar as classes do Bootstrap (col-md-6, btn-warning...) sem precisar consultar a documentação toda hora
CSS Peek pranaygp.vscode-css-peek Mostra a definição de uma classe/id sem trocar de arquivo (Ctrl+clique ou hover) Ótimo para investigar especificidade: você vê rapidinho todas as regras que miram o mesmo elemento
Auto Rename Tag formulahendry.auto-rename-tag Renomeia a tag de abertura e a de fechamento juntas Evita HTML quebrado ao editar a estrutura das seções da página de contato
Color Highlight naumovs.color-highlight Mostra a cor real ao lado de qualquer valor hexadecimal/RGB no CSS Facilita visualizar a paleta da marca (#0a0a0a, #ffbf00...) sem precisar copiar o código para um site externo
Prettier - Code formatter esbenp.prettier-vscode Formata automaticamente HTML/CSS/JS ao salvar, com indentação e espaçamento consistentes Mantém o código organizado enquanto o projeto cresce com media queries e várias seções
Bootstrap 5 & Font Awesome Snippets HansUXdev.bootstrap5-snippets Atalhos de digitação para componentes do Bootstrap e ícones do Font Awesome As duas bibliotecas usadas no Encontro 3 da semana — digite menos, acerte mais na sintaxe das classes
DicaVocê não precisa instalar todas de uma vez. Se for escolher só uma para começar, escolha o Live Server — é a mais usada em toda a trilha, não só nesta semana.
